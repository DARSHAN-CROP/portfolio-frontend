#  Darshan Corp (India) — Portfolio & Ecosystem

Official production-ready portfolio and open-source resource directory for **Darshan Corp**, built strictly following Apple India's design system, typography scales, and flat surface guidelines.

## 🚀 Overview
- **Brand:** Darshan Corp (India)
- **Primary Focus:** Full-Stack Web Development, Native Java Architecture, and Developer Workflows.
- **Design System:** Inspired by Apple India store architecture (pure white/light surfaces, zero elevation cards, and precision spacing).

## 🛠️ Tech Stack & Architecture
- **Frontend Core:** HTML5, CSS3 Design Tokens, Vanilla JavaScript (ES6+).
- **Backend & Desktop:** PHP 8, Native Java, Java Swing UI, and JDBC relational database connectivity.
- **Version Control:** Git, GitHub Organization workflows, and Codespaces integration.
